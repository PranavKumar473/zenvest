# Contributing to Zenvest

Thank you for contributing to Zenvest! To maintain code quality, security, and regulatory compliance, all contributors must follow these guardrails.

## Security & Secret Prevention

We enforce a strict **zero-secrets** policy. Never commit real passwords, API keys, private keys, or tokens.
